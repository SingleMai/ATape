# ADR-0046: One-time v0.4.5 manual release waiver

Status: Accepted by explicit user authorization on 2026-09-09

## Decision

The user explicitly authorized a one-time waiver of unfinished manual staging
acceptance and publication of v0.4.5, including real OAuth, multi-user/multi-Team
and production operations acceptance. They required all automated tests and
security scans to pass and release notes to disclose unverified acceptance.
This authorization is specific to v0.4.5 and does not inherit earlier waivers.

The release-gate Implementation adds only v0.4.5 to its closed authorization
list. Evidence binds a full candidate commit containing the release metadata,
global tools and updates feature, this decision, gate tests and release notes. Only the
v0.4.5 waiver record may change afterward. Unrelated changes invalidate the
binding and must be included in a new verified candidate before publication.

## Scope and consequences

Manual acceptance is waived, not passed. The staging attestation stays pending.
Real GitHub OAuth, two-user/two-Team acceptance, official topology and domain
egress isolation, TLS/WAF/callback settings, operational backup/restore,
secret-log sampling, rollback, candidate artifact acceptance and release signoff
remain unverified for this candidate.

Automated tests, package verification, PostgreSQL integration, dependency and
container scans, race/fuzz checks and self-hosting/paired restore remain blocking.
Authorization covers publishing the CLI and both first-party Adapter packages.
Server deployment and database migration remain separate actions.

Completed manual staging acceptance remains the default alternative. This
candidate-bound exception records the user's explicit choice; other releases
inherit neither the authorization nor a completed staging result.
