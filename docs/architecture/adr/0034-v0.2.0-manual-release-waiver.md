# ADR-0034: One-time v0.2.0 manual release waiver

Status: Accepted by explicit user authorization on 2026-09-08

## Exception

The user explicitly authorized publishing v0.2.0 with a one-time waiver of manual
staging acceptance, retaining every automated test and security gate and recording
unverified risks rather than marking tests passed. This overrides the manual
staging prerequisite for this release only; it does not remove future release gates.

The original staging attestation remains pending. A separate version-specific
waiver lists all unverified manual checks, the authorization, and a full candidate
commit. Release verification accepts it only for v0.2.0/auth-v1 and only if the
release tree differs from that ancestor by the waiver file itself. A later code
change requires a new decision rather than inheriting the waiver. No environment
variable or general-purpose bypass flag is added.

The GitHub Release prominently links the risk statement. Automated type/unit,
browser, CLI/Go, package/upgrade, database integration, dependency, race, fuzz,
container and paired-restore checks remain blocking. Browser setup is made explicit
in the release workflow, as in CI, so the existing browser gate can run there.

## Accepted uncertainty

Official deployment topology, real GitHub OAuth behavior, multi-user/multi-team
staging behavior, denial of the official-domain dependency, TLS/WAF/callback
configuration, operational paired backup/restore, secret-log sampling and rollback
have not been signed off for this candidate. CI results are not evidence of these
environment-specific checks. v0.2.0 changes authentication and requires the
documented migration; it must not be represented as a validated production upgrade.

## Alternatives

Waiting for manual acceptance is the normal policy but was explicitly waived.
Falsely completing the attestation or disabling release/security checks globally
would hide risk and is rejected. A separate candidate-bound record keeps the
exception auditable and leaves the ordinary completed-attestation path intact.
