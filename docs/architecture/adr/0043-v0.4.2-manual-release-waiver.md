# ADR-0043: One-time v0.4.2 manual release waiver

Status: Accepted by explicit user authorization on 2026-09-08

## Decision

After PR #92 passed CI and Security and merged the shared Collector diagnostic
fix and v0.4.2 release preparation, the user explicitly authorized a one-time
manual staging waiver for v0.4.2 and package publication. All automated tests
and security scans remain required, and release notes disclose unverified
acceptance. This decision does not inherit earlier release waivers.

The release-gate Implementation adds v0.4.2 to the closed authorization list.
Its evidence binds a full candidate commit containing this decision, gate tests
and release notes. Only the v0.4.2 waiver record may change after that candidate.
Further code changes or unrelated evidence invalidate the binding.

## Scope and consequences

Manual staging acceptance is waived, not passed. The staging attestation remains
pending. Real GitHub OAuth, two-user/two-Team acceptance, official topology and
domain egress isolation, TLS/WAF/callback settings, operational backup/restore,
secret-log sampling, rollback, candidate artifact acceptance and release signoff
remain unverified for this candidate.

Automated tests, package verification, PostgreSQL integration, dependency and
container scans, race/fuzz checks and self-hosting/paired restore remain blocking.
Authorization covers publication of the CLI and both first-party Adapters;
Server deployment and database migration remain separate actions.

Completed staging acceptance remains the default alternative. This candidate-bound
exception records the user's explicit choice; future releases inherit neither
its authorization nor a completed staging result.
