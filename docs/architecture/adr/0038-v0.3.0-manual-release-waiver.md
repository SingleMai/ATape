# ADR-0038: One-time v0.3.0 manual release waiver

Status: Accepted by explicit user authorization on 2026-09-08

## Decision

After PR #83 merged the CLI experience and coordinated v0.3.0 candidate, the
user explicitly approved a separate waiver of manual staging acceptance for
this release, retaining every automated test and security gate and disclosing
the unverified checks. The user plans to self-test after package publication.
This is a new authorization; the v0.2.0 waiver is not inherited or modified.

The release-gate Implementation recognizes only the two explicitly authorized
versions, v0.2.0 and v0.3.0. Each has its own evidence path and risk notice. The
v0.3.0 record binds a full candidate commit. Only that record may differ between
the candidate and the release tree. Code changes, another release's record, a
broader scope or incomplete risk disclosure invalidate the waiver. There is no
environment-variable bypass or automatic waiver of future releases.

The staging attestation remains pending. Release notes state that manual
acceptance was waived, not passed. All existing automated tests, database
integration, dependency and container scans, race/fuzz checks, self-hosting and
paired-restore checks remain blocking in the release workflow.

## Accepted uncertainty and scope

Real GitHub OAuth, multi-user/multi-Team behavior, official topology and domain
egress isolation, TLS/WAF/callback settings, operational backup/restore, secret-log
sampling and rollback have not been signed off for this candidate. Local PTY,
controlled login and ingestion tests are not evidence of those properties.
Publication releases the CLI and both first-party Adapters for online self-test;
it does not authorize a Server deployment or database migration.

## Alternatives

Completing staging acceptance before publication remains the normal policy.
The user chose a candidate-bound exception for this release. Marking the pending
attestation passed or disabling automated gates would misrepresent evidence and
is not part of the authorization.
