# ADR-0041: One-time v0.4.0 manual release waiver

Status: Accepted by explicit user authorization on 2026-09-08

## Decision

After PR #87 merged global tool configuration and the revised CLI journey, the
user explicitly approved a one-time manual staging waiver for v0.4.0 to publish
packages for self-test, retaining every automated check. This is separate from
the historical v0.2.0, v0.3.0 and v0.3.1 authorizations.

The release-gate Implementation adds only v0.4.0 to the closed authorization
list. The evidence binds a full candidate commit; only this version's waiver
record may differ afterward. Further code changes, unrelated evidence, a
different release or a broader scope invalidate the waiver.

Staging remains pending. Automated tests, PostgreSQL integration, dependency and
container scans, race/fuzz checks, self-hosting and paired restore remain
blocking. Release notes disclose the unverified manual acceptance rather than
claiming that it passed.

## Scope

Real GitHub OAuth, multi-user/multi-Team acceptance, official topology and domain
egress isolation, TLS/WAF/callback settings, operational backup/restore, secret-log
sampling, rollback, candidate artifact acceptance and release signoff remain
unverified. Publication covers the CLI and both first-party Adapters for self-test.
It does not authorize a Server deployment or database migration.

## Alternatives

Completed staging acceptance remains the default. This candidate-bound exception
implements the user's explicit choice. Future releases do not inherit the waiver,
and no automated gate or pending staging result is removed or falsified.
