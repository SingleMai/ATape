# ADR-0039: One-time v0.3.1 manual release waiver

Status: Accepted by explicit user authorization on 2026-09-08

## Decision

After PR #85 merged the CLI navigation and recovery improvements, the user
explicitly approved a one-time manual staging waiver for v0.3.1 so they can
self-test after package publication. This authorization is separate from the
historical v0.2.0 and v0.3.0 decisions.

The release-gate Implementation adds v0.3.1 to the closed list of authorized
versions. Its evidence binds a full candidate commit; only this release's waiver
record may differ between that candidate and the release tree. Code changes,
another release's evidence, broader scope or incomplete disclosure invalidate
the waiver. Future versions do not inherit it.

The staging attestation remains pending. Every automated test, database
integration, dependency and container scan, race/fuzz check, self-hosting and
paired-restore check remains blocking. Release notes disclose the manual waiver
without claiming that staging acceptance passed.

## Accepted uncertainty and scope

Real GitHub OAuth, multi-user/multi-Team behavior, official topology and domain
egress isolation, TLS/WAF/callback configuration, operational backup/restore,
secret-log sampling, rollback, candidate artifact acceptance and release signoff
remain unverified. Automated checks and local PTY tests do not replace them.
Publication covers the CLI and both first-party Adapters for user self-test;
it does not authorize a Server deployment or database migration.

## Alternatives

Completed staging acceptance remains the normal release policy. The user chose
a candidate-bound exception for this release. Fabricating completed evidence or
disabling automated checks is outside this authorization.
