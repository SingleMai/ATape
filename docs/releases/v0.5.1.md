# ATape v0.5.1: full-screen project console

The interactive CLI now reads as a persistent full-screen terminal application.
It keeps a stable brand header, top-level Projects, Tools and Settings navigation,
one framed workspace and a contextual footer. Project selection uses an accent
rail and a continuous low-contrast highlight, with compact labels on narrow
terminals.

`Add project` is now a one-shot modal instead of a top-level destination. Press
`n` from Projects to open the directory picker over a muted, non-interactive
Project list. The modal owns its input and footer until Enter advances setup or
Esc closes it. When tools have not been configured, ATape still opens the picker
first and continues to global tool selection after the user chooses a directory.

## Upgrade

Install `npm install --global @atape/cli@0.5.1` with Node.js 24 or newer, or run
`atape upgrade`. The coordinated CLI and official Adapter package version is
0.5.1. This release does not authorize or perform a Server deployment or database
migration.

## Validation and manual acceptance disclosure

Automated release gates cover repository checks, TypeScript and Go tests, the
full CLI presentation suite, installable release tarballs, PostgreSQL integration,
dependency and container security, race/fuzz checks and paired backup/restore.
The auth-v1 protocol and 180 days absolute Web Session lifetime are unchanged.

The staging attestation remains pending. Unverified manual checks are candidate
artifact acceptance, official topology, GitHub Provider staging smoke,
official-domain egress isolation, two-user/two-Team acceptance,
WAF/TLS/callback configuration, operational backup/restore, observability secret
sampling, rollback and release signoff.

Manual staging acceptance is waived, not passed, under the user's explicit
2026-09-12 request to submit this change to `origin/main` and publish it. Under
[ADR-0048](../architecture/adr/0048-release-request-manual-acceptance.md), that
request authorizes the candidate-bound manual-only waiver recorded in
[release evidence](evidence/v0.5.1-manual-waiver.json). Automated gates remain
mandatory. This authorization does not deploy the Server or migrate a database.
