Startup contract is internally consistent

        

      


      

        
Explicit public URLsCallbacks, CORS and cookies derive only from validated startup config—never Host or Forwarded headers.

        
HTTPS, with one exceptionPlain HTTP requires an explicit development flag and a loopback host. Private-LAN HTTP is rejected.

        
Exact instance isolationThe CLI stores credentials under the normalized Instance Origin and pins the discovered exact API Origin.

        
Deterministic CLI precedence--instance → ATAPE_INSTANCE_URL → saved active instance → https://atape.dev.

      


      

        Configuration boundary
        
    
          
  • Same-origin deployments omit Cookie Domain; split sibling deployments require one explicit common trusted parent.
    • 
          
  • The discovery request does not follow redirects. Origins contain no path, userinfo, query or fragment and normalize default ports.
    • 
          
  • Every secret-valued environment setting has a mutually exclusive _FILE form. Partial Provider config fails startup; changes take effect after restart.
    • 
          
  • Self-hosted instances own their Provider registration, database and keys. No request to ATape infrastructure is part of startup or login.
