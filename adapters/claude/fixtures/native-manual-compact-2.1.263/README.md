# Controlled manual compaction source evidence

Captured on 2026-10-08 from the installed Claude Code **2.1.263** executable,
whose SHA-256 was
`ef5d2909c8af49f31ab6d5487e90316777bc2fac170adfe8160716caa8aaf4f9`.
The executable generated these records in an isolated `CLAUDE_CONFIG_DIR` and
fresh temporary working directory. No personal conversation was read or resumed.

All model requests went to a deterministic Anthropic Messages SSE mock bound to
`127.0.0.1`, using a fake API key. No real model was invoked and there was no
provider charge. Prompt text, model response text, response IDs and usage counters
were supplied by the mock. Record UUIDs, parent links, the compaction boundary,
summary wrapper, preserved-message metadata, command records and synthetic resume
message were generated by the installed Claude Code. Token counters establish
projection behavior, not provider billing or actual tokenization.

## Invocation and snapshots

The CLI used `--restricted --safe-mode --tools ""`, `--permission-mode manual`,
`--permission-prompts none`, `--strict-mcp-config`, an empty MCP configuration,
`--no-chrome`, `--model claude-sonnet-4-6`, `--effort low`, an explicit synthetic
system prompt and `--print --output-format json`. Its minimal environment selected
the isolated config, loopback endpoint and fake key, and disabled nonessential
traffic, background tasks and updates. The first invocation used a fresh
`--session-id`; subsequent invocations used `--resume` with that exact ID.

An initial calibration with one user/assistant pair returned `Not enough
messages to compact.` locally, without a model request. That Session is excluded.
The retained Session completed these four invocations:

1. `ATAPE_NATIVE_COMPACT_SEED: Remember synthetic context cobalt heron 482.`
2. `ATAPE_NATIVE_COMPACT_SECOND: Also remember cedar fox 731.`
3. `/compact Preserve synthetic context cobalt heron 482 and cedar fox 731.`
4. `ATAPE_NATIVE_COMPACT_CONTINUE: Recall the synthetic context after compaction.`

Each invocation made one Messages request to the mock. `/compact` invoked the
built-in summarization workflow; it was not sent as an ordinary user prompt.
No context-window override or automatic-compaction trigger was used. The mock
accepted the installed CLI's actual summary request and returned controlled text.
It also exposed a count-tokens endpoint, but this run made no such request.

The three files are successive snapshots of **one native source JSONL**, not
three Sessions or separate source objects. Copy the selected snapshot into
`<sessionId>.jsonl` when exercising staged collection.

## Sanitization and scope

Only the isolated CWD, config-home path and encoded project-directory component
were replaced with fixture paths. Exact substitutions, original and sanitized
byte counts, SHA-256 digests and graph identities are recorded in
[provenance.json](provenance.json). UUIDs, parent links, flags, timestamps,
preserved-message metadata and all other decoded values were retained. Sanitized
fixtures are not byte-identical Raw.

This corpus establishes one root Session with two completed ordinary text turns,
one manual compaction, a singleton preserved assistant pointer and same-file
resume. It does not establish automatic or repeated compaction, broader retained
tails, tool-bearing compaction, subagent compaction, source UUID replay, partial
summarization, rewind, forks, cross-file continuation or other Claude versions.
Tests that mutate these snapshots must identify those mutations as synthetic.

The official [session explanation](https://code.claude.com/docs/en/how-claude-code-works#resume-or-fork-sessions)
describes resume under the same Session ID with appended messages. The official
[context-window guide](https://code.claude.com/docs/en/context-window#when-your-context-fills-up)
describes `/compact` with focus instructions. Those descriptions support the
invocation; the retained records establish this sampled graph and byte behavior.
